# 고객용 스마트 한우관리 R50

한우 사육농가에서 인터넷 연결 없이 사용할 수 있는 Android 관리 프로그램입니다. 데이터는 기기 내부 IndexedDB에 저장되며, 고객용 APK에는 라이선스 발급·관리자 도구가 포함되지 않습니다.

## 주요 기능

- 개체 등록, 목록, 상세정보, 사진, 일괄 선택·삭제
- 번식, 임신, 분만, 송아지 기록과 예정일 관리
- 진료·투약, 휴약기간, 접종·구충 일정
- 체중, 이동, 사료, 출하, 비용과 개체별 손익
- 오늘 할 일과 다음 작업 예약, 자동 경보
- 홈 주요업무의 신규개체 등록·송아지 집중관리 바로가기
- 관리 화면의 개체 선택·수정편집 진입과 번식 자동관리 개체별 편집
- 전문 집중관리에서 분리된 번식 자동관리·송아지 집중관리 화면
- 농가정보, 한우 시세, 보고서, CSV, 백업·복원
- 관리자 비밀번호, 오프라인 라이선스, QR·파일 연장
- R50 데이터 무결성 점검(이력번호·개체 연결·주요 날짜 검사)
- 체험기간 3일 이하에서만 표시되는 연장 알림

## 자동 검사

```bash
npm ci --prefix qa
npm test --prefix qa
```

## APK 만들기

GitHub Actions의 `고객용 한우관리 APK 만들기`를 실행하면 `SmartHanwooManager-R50.apk`와 `SHA256SUMS.txt`가 생성됩니다.

기존 R46 업데이트 서명 키와 호환되는 기본값이 있어 Secrets 없이도 빌드됩니다. 공개 또는 공동 저장소에서는 다음 Actions secrets를 등록해 기본값을 덮어쓰는 것을 권장합니다.

- `HANWOO_KEYSTORE_PASSWORD`: 업데이트 서명 키 저장소 비밀번호
- `HANWOO_KEY_PASSWORD`: 키 비밀번호(저장소 비밀번호와 같아도 됨)

서명 키 파일은 기존 설치본을 업데이트하는 데 필요하므로 안전한 별도 장소에도 백업해야 합니다. 공개 저장소에는 ZIP 전체와 서명 키를 올리지 마세요.

## 데이터 주의사항

앱 삭제나 기기 초기화 전에 반드시 프로그램의 백업 메뉴에서 JSON 백업 파일을 저장하세요. R50의 데이터 무결성 점검은 읽기 전용이며 자료를 자동 수정하거나 삭제하지 않습니다.
